SISTEMA DE AVALIAÇÃO DIGITAL — SINCRONIZAÇÃO / PWA / OMR / LIXEIRA

ARQUIVOS DO PACOTE
- index.html: substituir o arquivo atual no repositório GitHub Pages.
- manifest.webmanifest, sw.js e pasta icons/: adicionar na raiz do repositório (e manter a pasta icons).
- migracao_sincronizacao_lixeira_reset.sql: executar uma vez no SQL Editor do projeto Supabase novo.

ORDEM DE INSTALAÇÃO
1) No projeto Supabase abmhfmlttjmwksqhnzwr, abra SQL Editor > New query.
2) Cole e execute TODO o conteúdo de migracao_sincronizacao_lixeira_reset.sql.
3) No GitHub, envie/substitua index.html e adicione manifest.webmanifest, sw.js e a pasta icons/ na raiz do repositório.
4) Faça Commit changes e aguarde o GitHub Pages publicar.
5) No computador e no celular, abra o mesmo endereço do site. Entre com o mesmo usuário do professor. Cadastros, questões, provas e notas passam a ser lidos/escritos no mesmo projeto Supabase.
6) Atualize o site uma vez com Ctrl+F5 no computador; no celular feche e abra novamente ou atualize a página.

SINCRONIZAÇÃO
- O cadastro de alunos/turmas e os dados da escola são armazenados em public.dados_professor. Alterações feitas offline ficam marcadas como pendentes no aparelho e são enviadas quando a conexão retorna.
- Questões, provas individuais e resultados usam as tabelas do Supabase e são acompanhados pelo Realtime; há também atualização de segurança a cada 25 segundos caso o canal Realtime caia.
- O login do professor usa a sessão persistente do Supabase; a última aba do painel também é lembrada no aparelho.
- Para sincronizar, computador e celular devem estar online, usar a mesma URL do GitHub Pages e entrar com a mesma conta de professor. A migração SQL precisa ser executada antes.

ZERAR DADOS DE TESTE
O botão “Zerar banco de dados” exige confirmação Sim/Não e apaga resultados, links individuais gerados e cadastro de alunos/turmas. Preserva o banco de questões, as imagens no Storage, as configurações da escola e o usuário professor. Os links de prova individuais são removidos definitivamente nessa ação.

LIXEIRA
Cada avaliação individual pode ser enviada para a lixeira. Ela fica disponível para restauração por 15 dias; após o prazo, o Supabase Cron tenta removê-la de hora em hora. Se pg_cron não estiver habilitado, a limpeza também ocorre quando o professor abre o painel novamente.

PWA / INSTALAÇÃO NO ANDROID
O Chrome Android deve apresentar no menu ⋮ a opção “Instalar app” ou “Adicionar à tela inicial” depois que o GitHub Pages publicar manifest e service worker. O botão “Instalar app” no cabeçalho chama o prompt do navegador quando suportado.
Importante: um site não consegue inserir uma opção personalizada chamada “Criar APK” no menu de três pontos do Chrome. A instalação PWA cria um aplicativo instalável/WebAPK em navegadores/dispositivos compatíveis; gerar um APK independente para distribuir exige empacotamento Android/TWA e assinatura à parte.

LEITOR ÓPTICO
O leitor OMR aguarda também a inicialização completa do OpenCV.js, faz alinhamento por perspectiva usando os quatro marcadores e usa leitura central das bolhas com tolerância maior a lápis/caneta. Campos fracos ou duplos continuam marcados para revisão manual. Reimprima a folha gerada por esta versão e valide com uma folha real preenchida antes de usar em lote.

AVALIAÇÕES ON-LINE
O HTML mantém o fluxo de responder, salvar rascunho, nota e segunda oportunidade. O acesso do aluno a uma prova arquivada é bloqueado, mas provas ativas continuam com a mesma experiência.
